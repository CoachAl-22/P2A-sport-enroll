---
name: Term 4 schedule authority
description: How to resolve differences between the public SportsBiz schedule and the approved class finder.
---

Use the approved eight-row Term 4 table as the source of truth for class options advertised in the finder. The public SportsBiz schedule includes additional sessions; those are not automatically approved for the finder.

**Why:** The user explicitly selected the eight-row table and asked to hide other class options when the external SportsBiz schedule displayed more sessions.

**How to apply:** When changing the finder or class listings, confirm any additions outside the approved table with the user first. External booking URLs remain separately managed through admin and must not be overwritten without confirmation.
