---
name: MAJ parent view
description: Product decision on where families read Quick Notes
---

Parents read and receive Quick Notes in the MAJ parent view, using existing website
parent accounts and child links, rather than a separate parent-account system.

**Why:** The user chose the parent view inside MAJ when asked where parents should
read and receive Quick Notes.

**How to apply:** Keep parent-facing journey work inside MAJ and reuse website
parent identities. Do not create another parent login/account store.
